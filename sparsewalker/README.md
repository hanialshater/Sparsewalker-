# Sparse Walker implementation

Production/research implementation of Sparse Walker belongs here once promoted from experiments.

Planned components:

- router / product-key concept selection;
- persistent dynamic-support state;
- sparse graph transition and pursuit;
- concept readout;
- compiled and E2E sparse terminal;
- serving kernels and stateful inference.

Exploratory variants (S6 scan, structural reparameterization, backward-free learning) should remain under `experiments/` until they become stable components.
